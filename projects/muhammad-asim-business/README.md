# Muhammad Asim Business Website — Portfolio Demo

This is the redesigned **first portfolio website** for Muhammad Asim Web Agency.

## Design direction
- Business website, not an agency-style layout
- Green theme isolated to this portfolio project
- Original Muhammad Asim logo preserved
- Responsive on mobile, tablet, laptop and desktop
- 3-line mobile navigation
- Portfolio link removed from the business demo; the demo focuses on the business experience.
- Business pages uses the same **Live Demo** button style
- Contact Our Agency routes to the main agency contact page when this project is placed inside the main agency project folder

## Pages
- `index.html` — business homepage
- `about.html` — business-focused about page
- `contact.html` — business enquiry page
- `style.css` — green business styling and responsive navigation styles
- `script.js` — mobile menu, navigation behavior, year and enquiry form
