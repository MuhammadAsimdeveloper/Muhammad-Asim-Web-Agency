# Muhammad Asim Web Agency

Modern light-mode agency website with ten independent, interactive small-business website concepts.

## Agency pages
- index.html — homepage and services
- about.html — agency approach
- portfolio.html — ten filterable concepts
- contact.html — responsive project form that prepares a WhatsApp message; it does not silently submit data

## Standalone website concepts
- projects/restaurant.html — restaurant and cafe
- projects/wellness.html — wellness studio
- projects/home-services.html — home services
- projects/boutique.html — boutique and homeware
- projects/repair.html — repair service
- projects/fitness.html — fitness studio
- projects/consulting.html — consulting practice
- projects/bakery.html — bakery
- projects/tutoring.html — tutoring centre
- projects/photography.html — photography studio

Each page has its own brand direction, copy, SEO metadata, responsive layout, category filters and enquiry form. Enquiry forms prepare a WhatsApp draft for the agency. These are clearly disclosed fictional concepts: sample services, schedules and prices are not live offers, and no payments or real bookings are processed.

## Brand and SEO
- logo.svg — recreated vector wordmark
- mark.svg — matching monogram used in navigation
- favicon.svg — browser icon
- Unique page titles, descriptions, canonical URLs, Open Graph/Twitter metadata and page-level JSON-LD
- robots.txt and sitemap.xml include all public pages and ten demos
